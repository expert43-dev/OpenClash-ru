# OpenClash — русский интерфейс

Форк [vernesong/OpenClash](https://github.com/vernesong/OpenClash), основа — v0.47.156.
Автор исходного проекта: vernesong и участники OpenClash. Лицензия MIT сохранена.

Русская редакция 0.47.156.6 для OpenWrt с пакетным менеджером APK (25.12).
Переведён интерфейс LuCI: обзор, настройки, подписки, серверы, группы, сообщения
плагина. Названия протоколов, параметры конфигурации и бренды сохранены.
Перевод начат машинным способом; основные названия и действия выправлены вручную.
Замечания к оставшимся формулировкам принимаются через Issues.
Журналы самого ядра Mihomo и сторонние панели имеют собственную локализацию.

Изменения на странице обзора:

- IPgeo.ru и Mail.ru вместо PConline и IPIP.NET; IP.SB и IPIFY сохранены.
- Яндекс (ya.ru) и ВКонтакте (vk.ru) вместо Baidu и NetEase.
- Убран блок аватаров разработчиков; сведения об авторах сохранены в репозитории.
- Названия стран показываются по-русски. IP-запросы обновляются раз в 3–5 минут.
- После установки LuCI выбирает русский язык.
- В блоке состояния показаны основной сервер VPN и цепочка выбора, включая
  фактический узел «Автовыбора». Здесь же доступны ручной выбор и кнопка «Авто».
  Выбор из списка применяется сразу и сохраняется ядром (store-selected).
  Данные обновляются каждые 5 секунд. Переключение применяется к новым
  соединениям; отдельные сайты могут использовать другие правила маршрутизации.
- Версия работающего ядра читается через API. Обзор не запускает каждые 5 секунд
  отдельное упакованное ядро с `-v`, что предотвращает пики ОЗУ на слабых роутерах.
- При установленном стабильном ядре обзор не предлагает alpha-сборку из ленты
  OpenClash. Проверка обновлений плагина сохраняется.

Обновления плагина берутся из ветки `package` этого форка, обновления ядра —
из исходного проекта. VPN-профили, подписки и маршрутизация не изменяются.

## AmneziaWG

В редакторе узла выберите `WireGuard` и включите `AmneziaWG`.
В блоке «Импорт профиля AmneziaWG» выберите `.conf`, `.vpn` или JSON-файл
либо вставьте ссылку `vpn://`. Поддерживаются готовые клиентские профили
Amnezia Self-hosted, включая Qt-сжатие и параметры AWG 3.1. Файлы и ссылки
разбираются в браузере без сторонних сервисов. Если в экспорте несколько
профилей, выберите нужный, затем нажмите «Заполнить поля сервера».
Укажите конфигурацию и группу, сохраните и примените настройки.
Ключ подписки Amnezia Premium/API сам по себе не содержит готового профиля:
для него сначала экспортируйте оригинальный `.conf` через Amnezia.

Импорт включает «Сохранять локальный профиль WireGuard». Такие узлы остаются
в UCI при чтении конфигурации и добавляются в рабочую конфигурацию после
обновления подписки. Применяются выбранные группы (названия/регулярные выражения).
Для удаления отключите узел или удалите его и примените настройки.
Импорт рассчитан на один пир и не исполняет команды wg-quick. Профиль с
несколькими пирами или неизвестными полями отклоняется с сообщением.
Когда версия не указана и нет параметров 3.x, используется режим 1.x / 2.0
с просьбой сверить версию с сервером. DNS из профиля сохраняется; разрешение
имён остаётся на роутере (`remote-dns-resolve: false`).

Доступны параметры Jc/Jmin/Jmax, S1–S4, H1–H4, сигнатуры I1–I5,
ключ защиты заголовков, заполнение, таймеры и флаги AWG 3.1.
Для 3.0/3.1 в YAML используется `amnezia-wg-option.version: 3`.
Значения берите из конфигурации своего сервера; флаги 3.1 не включаются автоматически.
Импорт и экспорт сохраняют явные `false`/`0`, диапазоны и дополнительные параметры,
включая конфигурации с несколькими пирами. При отключении AmneziaWG создаётся
обычный узел WireGuard.

AWG 3.1 требует совместимого ядра Mihomo (проверено с официальным v1.19.32).
Установка пакета интерфейса сама по себе не обновляет ядро и не создаёт VPN-сервер.
Отдельные пакеты `kmod-amneziawg` / `luci-proto-amneziawg` к этой форме не относятся.
Описание параметров: [документация Mihomo](https://wiki.metacubex.one/config/proxies/wg/).

## Сборка и проверка

```sh
docker build -t openclash-ru-builder -f tools/Dockerfile .
docker run --rm -v "$PWD:/src" openclash-ru-builder python3 tools/check_localization.py
docker run --rm -v "$PWD:/src" openclash-ru-builder python3 tools/build_apk.py
```

В PowerShell вместо `-v` можно использовать
`--mount "type=bind,source=$($PWD.Path),target=/src"`.

Сборка использует официальный APK v0.47.156 с проверкой фиксированного SHA256.
Готовые базы и ресурсы, зависимости и скрипты установки сохраняются из исходного
пакета; код плагина и каталоги перевода собираются из этого репозитория.
После сборки проверяются метаданные и каждый распакованный файл, его права.
Файлы результата находятся в `dist/`, исходный APK кешируется в `build/`.
Перевод при сборке не обращается к внешним сервисам.

`tools/prepare_russian_catalog.py` — отдельный инструмент первоначального перевода
общедоступных строк через Google Translate. Он не нужен для обычной сборки.
Никогда не передавайте ему конфигурации, подписки, журналы или пароли.
Ручные исправления находятся в `tools/russian_overrides.json`, итоговый каталог —
`luci-app-openclash/po/ru/openclash.ru.po`.

## Установка

Сначала сохраните `/etc/config/openclash`, `/etc/openclash`, `/etc/config/luci`
и свои скрипты подписки. Проверьте наличие свободного места и доступ к роутеру.
Установка на OpenWrt 25.12 с APK:

```sh
apk add --allow-untrusted /tmp/luci-app-openclash-0.47.156.6.apk
```

После установки обновите страницу браузера без кеша. Пакет не подписан ключами
официального репозитория OpenWrt; сверьте его с опубликованным `SHA256SUMS`.
Для отката установите сохранённый официальный APK v0.47.156 и восстановите
предыдущий язык LuCI. IPK для старых версий OpenWrt пока не публикуется.

Оригинальная документация: [README.upstream.md](README.upstream.md).
