# OpenClash — русский интерфейс

Форк [vernesong/OpenClash](https://github.com/vernesong/OpenClash), основа — v0.47.156.
Автор исходного проекта: vernesong и участники OpenClash. Лицензия MIT сохранена.

Русская редакция 0.47.156.1 для OpenWrt с пакетным менеджером APK (25.12).
Переведён интерфейс LuCI: обзор, настройки, подписки, серверы, группы, сообщения
плагина. Названия протоколов, параметры конфигурации и бренды сохранены.
Перевод начат машинным способом; основные названия и действия выправлены вручную.
Замечания к оставшимся формулировкам принимаются через Issues.
Журналы самого ядра Mihomo и сторонние панели имеют собственную локализацию.

Изменения на странице обзора:

- IPgeo.ru и Mail.ru вместо PConline и IPIP.NET; IP.SB и IPIFY сохранены.
- Яндекс (ya.ru) и ВКонтакте (vk.ru) вместо Baidu и NetEase.
- Убран блок аватаров разработчиков; сведения об авторах сохранены в репозитории.
- Названия стран показываются по-русски. IP-запросы обновляются раз в 3–5 минут.
- После установки LuCI выбирает русский язык.

Обновления плагина берутся из ветки `package` этого форка, обновления ядра —
из исходного проекта. VPN-профили, подписки и маршрутизация не изменяются.

## Сборка и проверка

```sh
docker build -t openclash-ru-builder -f tools/Dockerfile .
docker run --rm -v "$PWD:/src" openclash-ru-builder python3 tools/check_localization.py
docker run --rm -v "$PWD:/src" openclash-ru-builder python3 tools/build_apk.py
```

В PowerShell вместо `-v` можно использовать
`--mount "type=bind,source=$($PWD.Path),target=/src"`.

Сборка использует официальный APK v0.47.156 с проверкой фиксированного SHA256.
Готовые базы и ресурсы, зависимости и скрипты установки сохраняются из исходного
пакета; код плагина и каталоги перевода собираются из этого репозитория.
После сборки проверяются метаданные и каждый распакованный файл, его права.
Файлы результата находятся в `dist/`, исходный APK кешируется в `build/`.
Перевод при сборке не обращается к внешним сервисам.

`tools/prepare_russian_catalog.py` — отдельный инструмент первоначального перевода
общедоступных строк через Google Translate. Он не нужен для обычной сборки.
Никогда не передавайте ему конфигурации, подписки, журналы или пароли.
Ручные исправления находятся в `tools/russian_overrides.json`, итоговый каталог —
`luci-app-openclash/po/ru/openclash.ru.po`.

## Установка

Сначала сохраните `/etc/config/openclash`, `/etc/openclash`, `/etc/config/luci`
и свои скрипты подписки. Проверьте наличие свободного места и доступ к роутеру.
Установка на OpenWrt 25.12 с APK:

```sh
apk add --allow-untrusted /tmp/luci-app-openclash-0.47.156.1.apk
```

После установки обновите страницу браузера без кеша. Пакет не подписан ключами
официального репозитория OpenWrt; сверьте его с опубликованным `SHA256SUMS`.
Для отката установите сохранённый официальный APK v0.47.156 и восстановите
предыдущий язык LuCI. IPK для старых версий OpenWrt пока не публикуется.
